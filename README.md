## 挡增量：只走一条路线（A）

开灌 = 在互斥账册里占一条持有记录，并给窗口挂上互斥号。从这一刻起：

- **日增量先拒后写**：`BEGIN EXCLUSIVE` 里查互斥账册，命中就直接 409 并抛短句，
  目标表 `landing_rows` 一行都不写。不存在“先混入再整笔回滚”的旁路，
  所以库里不会出现两种落库结果并存。
- **回灌先验后写**：重放同一把锁里预检该日落点，绝不靠主键撞出来报错；
  撞主键不算业务结果，只是被提前拦掉的事故。
- **开灌态与可写门槛对齐**：`执行中` 但没有持有互斥（或反之）判为失配，
  卡片亮红、重放与日增都拦、对账判“对账存疑”。同表其它窗口的卡片同样亮失配。
- **两侧仓管同点开灌**：排他锁 + `ux_mutex_active` 唯一索引，只有一侧拿到互斥号，
  另一侧 409。缺锁就会双写落点，因此互斥号是列表、详情、对账三处共用的凭据。

对账不再只看切片数：同时核落点行数、日增混入行数与门槛状态，
任一项不为零即“对账存疑”，不会虚绿。
